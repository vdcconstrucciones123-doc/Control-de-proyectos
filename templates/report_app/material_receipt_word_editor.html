Falta conectar el servidor de documentos

La aplicación conserva el acta y sus herramientas actuales. Para abrir el editor Word, configura estas variables en Render y reinicia el servicio:

  • ONLYOFFICE_DOCUMENT_SERVER_URL: URL HTTPS pública de ONLYOFFICE Docs.
  • ONLYOFFICE_JWT_SECRET: el mismo secreto JWT configurado en ONLYOFFICE Docs.

El servidor de documentos debe poder acceder a esta aplicación para descargar el DOCX y enviar los cambios guardados.
